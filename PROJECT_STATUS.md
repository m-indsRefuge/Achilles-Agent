# Achilles Agent Project Status

## Current State

Achilles is in an early implementation and stabilization phase.

The repository contains architecture planning, memory-layer concepts, and partial implementation work. The full agent has not yet been fully validated on development hardware.

## Current Constraint

The current device is resource constrained, which limits local development and testing.

## Next Milestone

When the new development machine is available, the first priority is to establish a clean runnable baseline.

## First Runtime Checklist

1. Clone the repository.
2. Create a Python virtual environment.
3. Install dependencies.
4. Run pytest.
5. Identify failing tests.
6. Confirm indexing works on a small sample project.
7. Confirm retrieval returns expected chunks.
8. Add or repair CLI entry points.
9. Add CI.
10. Move to branch and PR workflow only.

## Priority

Stability first.
